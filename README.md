# Автоматизация тестирования API [Яндекс.Самокат](https://qa-scooter.education-services.ru/)

Проект автоматизированного тестирования REST API веб-сервиса для заказа самокатов, покрывающий ключевые сценарии платформы, включая валидацию создания и авторизации курьеров, оформление заказов с различными параметрами и получение списков данных.

🛠️ Технологии:

* **Python 3.13** — основной язык программирования
* **Pytest** — фреймворк для написания, параметризации и запуска тестов
* **Requests** — библиотека для отправки HTTP-запросов и работы с API
* **Allure Framework** — инструмент для генерации детальных отчетов

📋 Особенности реализации:

* **Methods Object Model** — архитектура проекта разделена на базовые конфигурации, классы со служебными API-методами (`methods/`) и изолированные тест-кейсы для упрощения поддержки кода
* **Разделение данных** — все тестовые сценарии избавлены от жестко зашитых данных, статические и динамические payloads вынесены в отдельный файл `data.py`
* **Управление состоянием данных** — применение фикстур с механизмом `yield` гарантирует независимость тестов: учетные записи курьеров автоматически создаются перед тестом и полностью удаляются после его завершения

📥 Как установить проект:

1. Клонируйте репозиторий с проектом:
   ```bash
   git clone <ссылка_на_ваш_репозиторий>
   cd Sprint_7
   ```
2. Создайте и активируйте виртуальное окружение (venv):
   * Для Windows:
     ```bash
     python -m venv venv
     venv\Scripts\activate
     ```
   * Для macOS / Linux:
     ```bash
     python3 -m venv venv
     source venv/bin/activate
     ```
3. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```

🚀 Как запустить проект: Перед запуском убедитесь, что виртуальное окружение активировано в вашем терминале. 

* Запуск всех тестов в проекте из корня репозитория:
  ```bash
  python -m pytest
  ```
* Запуск тестов с подробным выводом результатов (verbose режим):
  ```bash
  python -m pytest -v
  ```
* Запуск конкретного тестового файла:
  ```bash
  python -m pytest tests/orders/test_create_orders.py -v
  ```
* Запуск определенного класса тестов:
  ```bash
  python -m pytest tests/orders/test_create_orders.py::TestCreateOrder -v
  ```

📊 Как сгенерировать Allure-отчет: Для сборки отчета на компьютере должна быть установлена консольная утилита Allure CLI.

Запуск тестов и сборка результатов в готовую статичную папку отчета:
```bash
python -m pytest --alluredir=allure-results --clean-alluredir && allure generate allure-results --clean -o allure-report
```
